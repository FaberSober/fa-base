# ADR-004：菜单管理界面优化

- 状态：Proposed
- 日期：2026-09-19
- 范围：`frontend/apps/admin` 菜单管理页面、菜单编辑弹窗及菜单树交互
- 关联页面：`/admin/system/base/menu`

## 1. 背景

当前菜单管理页面使用 `BaseTree` 渲染菜单树，并在 `titleRender` 中通过固定宽度拼接图标、ID、类型、状态、路由和操作按钮。菜单数量增加后，页面缺少表头、搜索和筛选，长文本容易挤压布局，行内操作和右键操作也存在重复。

菜单数据同时包含模块、菜单和按钮三种层级，且删除父节点会级联删除所有子节点。因此需要在不改变现有菜单接口和数据结构的前提下，优先改善管理效率和操作安全性。

## 2. 决策

采用“树形表格 + 分层编辑表单”的方案：

1. 保留现有 `rbacMenuApi`、菜单树数据结构和拖拽排序接口。
2. 菜单页面改为菜单专用的树形表格布局，首版不修改公共 `BaseTree` 的行为。
3. 终端类型、搜索筛选、展开收起和新增操作统一放入顶部工具栏。
4. 行操作统一收敛到操作菜单，按钮节点不能继续新增子节点。
5. 菜单编辑表单根据“模块、菜单、按钮”动态显示字段，并限制合法父节点。
6. 删除、拖拽排序、状态切换等操作补充明确的成功、失败和风险提示。
7. 当前仅支持网页和 APP；未来终端类型通过数据驱动扩展，不在本次增加新的终端枚举。

## 4. 开发说明

### 4.1 树形表格和工具栏

- 在菜单页面新增页面级树形表格组件，不直接扩展公共 `BaseTree` 的复杂行为。
- 首列展示层级关系，其他列保持固定或弹性宽度；ID、路由和权限标识支持省略与复制。
- 顶部统一放置网页/APP切换、搜索、状态筛选、类型筛选、展开全部、折叠全部、刷新和新增入口。
- 默认保持当前 scope 的展开状态；切换 scope 后使用对应 scope 的树数据和展开状态。
- 终端类型配置使用数组或字典驱动，当前只提供网页和 APP。

### 4.2 菜单操作和拖拽

- 行操作使用“更多”菜单，保留新增下级、编辑、复制和删除。
- 根据节点等级隐藏不允许的新增操作，按钮节点不得继续创建子节点。
- 拖拽只允许在同一 scope 内进行，并限制非法父级关系。
- 调用 `changePos` 时显示保存状态；失败时恢复本地顺序并重新加载数据。
- 状态切换避免直接修改传入对象，更新失败时恢复开关状态。

### 4.3 菜单编辑表单

- 模块表单只保留名称、图标、状态等必要字段。
- 菜单表单展示父级菜单、名称、图标、链接类型、链接地址和状态。
- 按钮表单固定所属页面，展示按钮名称、权限标识和状态，不展示无关图标字段。
- 切换链接类型时清理不再适用的链接值，避免旧值残留。
- 编辑菜单时禁止选择自身及其子孙节点作为父级。
- 前端限制与后端层级校验保持一致，不能只依赖前端隐藏选项。

### 4.4 删除和安全提示

- 删除叶子节点使用普通确认。
- 删除包含子节点的模块或菜单时，显示子节点数量并明确说明会级联删除权限节点。
- 删除完成后刷新树和当前筛选状态；失败时保留原页面状态并展示错误信息。
- 状态禁用是否级联影响子节点需要沿用后端现有语义；如果不级联，页面应明确只影响当前节点。

### 4.5 样式和可访问性

- 使用现有 `--fa-*` 主题变量和 Ant Design token，不新增与主题冲突的固定颜色。
- 长名称、链接和权限标识使用 Tooltip 展示完整内容。
- 复制按钮使用明确的按钮语义和提示，不让整段文本承担隐式点击行为。
- 操作按钮支持键盘访问、焦点状态和禁用状态。
- 验证亮色、暗色、长文本、空树、加载失败和窄屏场景。

## 5. 非目标

- 本 ADR 不修改租户权限配置面板。
- 本 ADR 不新增菜单数据字段，不改变现有 `scope`、`level`、`parentId`、`linkType` 和 `linkUrl` 的业务含义。
- 本 ADR 不在当前版本增加小程序、开放平台等新的终端类型。
- 本 ADR 不实现菜单批量管理、导入导出、审计日志和版本回滚。
- 首版不修改公共 `BaseTree`，除非页面级组件无法满足既有能力且经过单独评估。

## 6. 验收标准

- 菜单名称、类型、图标、ID、路由/权限标识、状态和操作列在不同窗口宽度下保持稳定对齐。
- 可以按名称、ID、路由/权限标识搜索，并自动展开命中节点的父级路径。
- 模块、菜单、按钮三种层级的新增和编辑入口符合层级约束。
- 按钮节点不显示新增下级操作，非法父级节点不能被选择。
- 拖拽排序成功后顺序正确，接口失败时页面不会保留错误顺序。
- 删除包含子节点的菜单前能够看到级联删除提示和下级数量。
- 状态切换成功、失败和加载中状态清晰可见。
- 编辑弹窗根据菜单等级显示字段，切换链接类型不会提交过期字段值。
- 亮色、暗色、空数据、加载中、错误和窄屏场景均可正常使用。
- 完成受影响前端文件的格式检查、局部类型检查和关键交互验证。

## 7. 实施顺序

1. 新增菜单页面工具栏和树形表格基础布局。
2. 接入 scope 切换、搜索筛选、展开收起和长文本展示。
3. 收敛行操作，增加菜单层级和父级选择限制。
4. 优化拖拽排序、状态切换和删除确认交互。
5. 改造菜单编辑弹窗的动态字段和表单清理逻辑。
6. 补齐主题、响应式、可访问性和异常状态处理。
7. 完成局部格式检查、类型检查和页面回归验证。
