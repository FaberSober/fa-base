# 七牛存储访问类型切换操作手册

适用范围：在隔离的测试环境中验证七牛 Bucket 与系统 `qiniuAccessType` 的公开/私有切换、访问回归和回退。此流程不适用于直接切换生产 Bucket。

## 切换前准备

- 使用独立测试 Bucket、测试域名和测试凭证；准备一张图片、一个文本文件及一个可预览文档，避免使用真实用户文件。
- 确认当前部署版本同时支持公开和私有模式，记录应用版本、Bucket 当前访问策略及系统配置值。记录中不要粘贴 AK、SK、上传 Token、签名 URL 或 session。
- 选择维护窗口，暂停测试环境的上传和文件访问。确认可以管理 Bucket ACL 与 CDN 缓存；若旧公开 URL 经过 CDN，准备按对象路径刷新缓存，或使用全新对象路径避免缓存命中。
- 先在公开模式完成基线检查：系统访问类型与 Bucket 权限均为公开，上传、原图、缩略图、文本及文档预览符合原有行为。

## 切换为私有

1. 暂停测试环境的文件写入和访问，避免系统配置与 Bucket ACL 处于不一致状态。
2. 将测试 Bucket 改为私有，并按需清理测试域名/CDN 中先前缓存的公开对象。
3. 在系统配置中将七牛访问类型改为“私有”，确认保存成功；依当前实现，存储配置重建及上传 Token 缓存清理应立即生效，无需手工清除缓存。
4. 恢复测试流量，使用已登录的普通账号上传一组新测试文件，并保留新旧文件 ID 供回归。
5. 执行以下检查：
   - 已登录访问 `getFile/{fileId}`、`getFilePreview/{fileId}`、`getFileStr/{fileId}`；原图/缩略图应可读，文本应返回内容，下载/预览重定向应使用短效签名。
   - 无登录态访问普通私有文件入口应被拒绝；直接打开不含签名的旧七牛 URL 应无法读取对象。必要时先刷新 CDN 缓存，再用新对象路径复核。
   - 验证无缩略图时回退原图；已登记的历史七牛文件仍按当前私有配置受保护；登录页中由服务端明确配置的 Logo/背景素材仍可展示。
   - 等待签名有效期超过 600 秒后，旧签名 URL 应失效；已登录页面重新申请资源后应获得可用的新链接。
   - 上传、直传登记、App/H5 预览、OnlyOffice 和应用发布下载按测试环境实际使用范围回归；确认签名 URL 未写入文件记录或完整请求日志。
6. 通过上述检查后恢复正常测试流量，并记录结果、应用版本和测试文件 ID；不要记录文件内容、密钥、票据或签名 URL。

## 回退为公开

1. 暂停测试环境的文件写入和访问，避免两侧配置短暂不一致。
2. 将测试 Bucket 改回公开，并在系统中将七牛访问类型改为“公开”。公开模式会重新允许匿名读取 Bucket 中的对象。
3. 按需刷新测试域名/CDN 缓存，恢复测试流量。
4. 复核普通文件接口、已有公开 URL、缩略图及上传登记；同时确认本地和 MinIO 存储行为不受影响。
5. 如果回退失败，保持维护状态并分别核对 Bucket ACL、系统访问类型、域名/CDN 缓存和应用版本；不要通过匿名签名或暴露长期凭证绕过检查。

## 风险边界

- Bucket ACL 和系统访问类型必须保持一致。系统选“私有”不会自动关闭 Bucket 或 CDN 的公开访问；系统选“公开”也不会让私有 Bucket 的裸 URL 可读。
- 回退为公开会重新开放 Bucket 对象，不是无风险的自动降级。签名 URL 在有效期内仍可由持有者使用，账号退出不会立即撤销已签发链接。
- 私有模式覆盖整套七牛存储，不提供单文件 ACL 或即时撤销单条签名链接。
