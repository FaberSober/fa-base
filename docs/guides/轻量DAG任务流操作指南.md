# 轻量 DAG 任务流操作指南

适用页面：系统设置 → 定时任务（`/admin/system/base/job`）。更新：2026-11-10。

## 创建与编排

1. 点击“新建任务流”，在配置面板填写名称、并发上限；需要文件日志时开启“记录详细日志”。
2. 点击顶部“＋”打开任务库，通过分组与搜索定位任务；点击卡片添加。节点直接引用 `@FaJob` 注册的 Java 类，无需在普通任务列表另建记录。同一类可添加为多个独立节点。
3. 从上游节点右侧连接到下游节点左侧，形成从左到右的依赖。无前驱的节点自动显示“入口”，可有多个入口；下游等待全部前驱成功后启动。
4. 拖动节点调整位置，使用自动布局整理画布。选中节点或连线后按 Delete / Backspace 删除；缩放及鹰眼工具位于画布底部。
5. 点击“保存”将定义写入服务器。JSON 查看/编辑支持校验和回填画布，回填后仍须保存。暂存仅保留当前页面草稿，刷新会丢失。

## 预检与运行

- 保存后点击“预检”查看依赖层级与重复任务类提示；预检不会执行业务，层级也不代表必须等待上一整层结束。
- 顶部“执行”使用服务器已保存的定义，会真实调用业务任务。未保存修改不参与本轮；运行中保存的新配置只影响下一轮。
- 并发上限限制本轮活动任务数；同一轮中的同类任务串行。异步任务等待受支持的跟踪工作实际结束，主方法返回不代表完成。
- 同一流程有执行中、停止中或未确认运行时，不能再启动新一轮。不同流程之间、流程与普通任务独立 Cron 之间不保证任务类互斥。
- 失败阻断依赖后代，无依赖的独立分支可继续；重新执行会创建新轮次并重跑全部节点，不是从失败处继续。

## Cron 与停止

1. 在流程配置填写 Cron 并保存，在任务列表启用调度。新建流程默认暂停；已启用时修改 Cron，须先暂停再修改。
2. “暂停调度”只停止未来触发，当前轮次继续。重叠定时触发会跳过，不补跑错过的时刻。
3. 运行详情的“停止本轮”不再启动新节点，已运行任务继续收尾；不会强制终止 Java 线程，也不撤销已产生的业务数据。
4. 停止本轮不会暂停 Cron；如需停止后续轮次，先在任务列表暂停调度。

## 查询运行与排查日志

- 打开历史记录，按运行 ID、状态、来源或开始时间查询，使用分页浏览；点击“查看”进入对应运行，返回列表后继续查询。
- 运行图使用本轮关联的不可变历史定义，不受后来编辑影响。点击图节点或时间线卡片双向高亮定位；卡片显示时间，日期范围集中显示在总耗时左侧。
- 顶部“编排日志”查看开始、节点调度/结果、阻断、停止与收尾；节点卡片上的日志图标查看对应业务文件，两者不混写正文。支持增量跟随与下载。
- 详细日志开关按启动版本冻结，仅对开启后新轮次生效。未记录的旧轮次不能补生成；文件过期清理后仍保留数据库摘要。
- 耗时包含等待与排队，流程总耗时为整轮经过时间，不是所有节点耗时之和。未确认工作不伪造结束时间。

## 状态与故障处理

| 状态 / 现象 | 含义及操作 |
| --- | --- |
| 执行中 | 仍有任务或依赖待推进；可查看日志。停滞时用“核对状态”同步已持久化的业务结果，不重新执行业务。系统也会周期补偿。 |
| 停止中 | 已接受停止请求，等待已启动任务真实收尾。 |
| 成功 / 失败 / 已停止 | 本轮已收尾；失败不回滚业务。排查影响后可完整重新执行。 |
| 未确认 | 不能确认实际业务结束，后续不放行，继续占用同流程互斥。先核查业务结果；目前尚无人工解除入口，不要直接改数据库状态放行。 |
| 日志按钮不可用 | 执行前未开启详细日志，或该节点尚未启动。已启动节点仍可通过业务记录查看归属。 |
| 文件不可用 | 文件可能过期清理、目录改变或存储异常；检查服务端日志配置及存储。 |

服务重启会核查已提交的业务终态，未知工作转为未确认，不自动重跑。文件事件为尽力记录，故障窗口可能缺失，数据库运行状态是事实来源。

## 当前边界

- 首版只允许一个实例承担编排调度与恢复扫描；不提供多实例接管。
- 暂不支持自动重试、失败续跑、节点参数/输出传递、条件分支或嵌套流程。
- 日志与定义版本有关联保护，不提供随意删除关联记录的能力。
- 升级结构统一由 `1.0.54` 的 MySQL / PostgreSQL 脚本维护；早期测试库须核对结构后使用对应补丁，不删除升级记录强行重跑。
