- 管理端 `remoteClient/components` 新增状态图及监测逻辑；历史仅存前端内存，关闭页面即释放。
- `RemoteClientBiz` 返回跨节点在线信息与 `clientInstanceId`；状态订阅按用户和安装实例跟踪，不按账号自动换设备。
- `RemoteLogWebSocketService` 区分申请中与已确认会话，通过 Redis 短期占用控制及消息主题跨节点传递；不增加数据库表。
- `mobile` 与 `mobile-x` 收到开启指令并建立采集后发送回执；手动关闭、权限失效、占用冲突及 30 分钟超时终止自动恢复。
- 自动恢复保留日志、筛选和滚动设置，恢复前沿用原采集截止时间；不补采离线期间的日志。
- 按目标模块执行测试和检查；不启动浏览器或开发服务器，不提交无关改动。

## 人工验收

1. 使用更新后的 App 开启采集，确认回执后显示采集中；无日志时心跳图仍有更新。
2. App 断网并恢复，确认离线/等待恢复、新连接恢复采集，旧日志保留。
3. 管理端断网并恢复，确认显示状态未知并重新订阅、恢复采集。
4. 手动停止后重复断网，确认不会自动开启；旧回执不会覆盖停止状态。
5. 同账号两台设备确认仅跟踪选中实例；两个管理员同时采集应提示占用。
6. 多实例环境中 App 和管理端分别连接不同节点，检查状态、回执、日志和停止指令。
7. 检查过期、无权限、客户端版本未更新和 Redis 不可用时的提示；不误显示采集中。
